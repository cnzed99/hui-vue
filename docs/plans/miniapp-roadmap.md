## M2 验证记录

- 小程序：文档打印目录、本地文件选择壳和固定演示解析状态已实现；真实文件不会上传，页面明确区分演示结果。
- 服务端：新增匿名只读静态目录；不接数据库，不返回租户、门店、用户、价格、订单、支付或打印机字段。
- 代理：只精确发布 `GET /app-api/print/miniapp/catalog`；写方法拒绝，相邻 `/app-api/` 路径不代理。
- 构建：小程序 `type-check`、微信构建和 H5 构建通过；后端主源码编译和跳过测试打包通过。既存测试源码缺少 Mockito 依赖，完整后端测试未通过，不计为测试通过。
- 运行：H5 在线显示服务端目录；后端受控停止时明确显示本地 fallback，恢复后重新连接；固定演示解析状态完成浏览器烟测，未点击真实文件选择。
- 独立审查：`astra_reviewer` / GPT-6 Astra High；设计初审要求收窄 Nginx、补齐 MP HTTPS fallback 和响应校验，修复后源码候选与云端运行证据均 PASS。结论只覆盖开发候选，不代表正式上线或用户验收。
- 普通 UI 批量审查：`sol_reviewer` / GPT-6.1 Sol High；发现后台目录探测缺少超时，补 5 秒 `AbortController` 后复审 PASS，无剩余 P1/P2。完整后台构建、微信真机和真实文件选择仍为 `NOT_RUN`。

## 当前完成度口径

- 小程序专项按 M0–M6 的可验证结果估算，不用页面数量代替端到端完成度。
- 打印系统总目标同时包含服务端、管理后台、小程序、测试、部署和外部集成；真实微信和真实打印未接入时不得标记完成。
- 当前小程序专项约完成 28%；打印系统总目标约完成 36%。该比例按可验证闭环估算，微信真机、真实上传、计价订单、支付和打印均未完成。
