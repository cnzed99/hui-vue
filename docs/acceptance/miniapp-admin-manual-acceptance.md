# 小程序与配套后台验收操作用例

版本：2026-11-01

适用范围：当前云端开发演示环境；单商家、单门店。

说明：支付和打印均为**模拟**；微信真机、真实支付退款、真实打印机不在本次验收范围。

## 一、验收准备

1. 小程序 H5：http://127.0.0.1:18080/miniapp/#/
2. 配套后台：http://127.0.0.1:18080/login?redirect=/print/demo-orders
3. 使用现有演示管理员账号登录；本文不记录密码。
4. 准备一份不超过 2MB、20 页的 PDF；建议 2～3 页。
5. 每项记录：`□通过  □不通过  问题：__________`
