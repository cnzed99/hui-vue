# 首批真实验收与剩余开发映射

本计划基于服务器上的 V1.0 任务书、126 项任务、53 入口和 23 类表单，以及本轮实际源码检查。它是验收执行依据，不代表验收通过。原任务清单不改写，旁路追踪文件为 task-traceability.json；快照、文件哈希及代码版本见 source-snapshot.json。

## 执行位置与证据要求

所有开发、构建、测试、数据库和演示均在用户自购服务器执行。旧 Codex 云环境仅导出现有成果；本机仅 SSH 连接、协调和交付备份。原生产后台严格只读，不查询历史业务、不试提交、不产生真实资金或打印操作。

每条验收结果必须保存：用例 ID、对应需求/任务、代码版本与工作树差异、环境版本、合成夹具、实际请求方法/已核验路径（不记录凭据）、预期与实际结果、运行时间、证据文件和未完成项。仅测试计划/测试代码存在不能计为通过。密码、令牌、私钥和上传文件内容不进入日志/版本库。

结果分层：静态检查、编译构建、自动化接口/数据库测试、浏览器交互、原站视觉对照、独立复核、用户验收、物理设备验证。每层独立，不互相替代。纸张计价样例是新系统用户确认规则，不是原站算法实测。

服务器仅 60 GB 系统盘。每批检查 df/du；大操作前至少 10 GiB 可用。单次仅一项大构建，避免与数据库/服务抢占内存。保留必要依赖缓存、源码、数据库、可恢复备份和诊断；清理明确无用的安装包、重复解压目录、过期日志、临时夹具。清理记录精确路径和前后占用，不对未知目录广泛删除。测试文件只能清理由该轮创建的独立目录，不能删除业务文件。

## 当前检查事实

- backend 固定上游提交含真实 Yudao 登录、退出、权限查询代码；仅有源码不能证明本环境登录成功。
- 打印前端包含公共外壳及 P47 触屏广告静态样板，保存按钮 disabled，未接业务接口；其他 52 入口在此打印样板中禁用。不能把上游现成管理页面当作原后台全部功能完成。
- print-preview 仅 cloud 模式显式开关启用；它是视觉标本，不授予后端权限，不能代替正式登录及业务管理路由。
- 已核验认证路径（按源码默认 admin-api 前缀）：POST /admin-api/system/auth/login、GET /admin-api/system/auth/get-permission-info、POST /admin-api/system/auth/logout。运行配置若改前缀必须同步核验。
- 未认证响应由 AuthenticationEntryPointImpl 返回 CommonResult.code=401；HTTP 状态可能为 200。不得仅按 HTTP 200 判为授权成功。
- AuthLoginReqVO 当前用户名为 4–30 位字母数字、密码上限 16 位。初始凭据须符合实际约束，或源码明确调整并重新构建验证；不能生成不能登录的初始密码。
- 上游 FileController 的 /{configId}/get/** 标为 @PermitAll 和 @TenantIgnore，不满足打印用户文件的归属隔离。打印链路不得直接依赖此匿名入口；需实现受控下载，并测试无登录、跨用户、跨门店、过期授权和路径变种。
- 本轮不启动服务、不写数据库、不调用真实业务接口。全部运行验收尚为 NOT_RUN。

独立脚本 ops/acceptance/auth_smoke.py 只访问已查证的认证端点；默认仅负向 GET，不改变业务。正向登录/退出须 --allow-login 并指定服务器上的受限凭据 JSON 文件。它不覆盖角色权限、DB 重启持久化、刷新令牌、打印业务、视觉或用户验收。运行前先确认服务就绪和实际租户 ID，不假定租户为 1。
