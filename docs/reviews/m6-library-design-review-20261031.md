## 初审

结论：`CHANGES_REQUIRED`。主要阻断项：

1. `entryId + contentVersion` 未明确纳入幂等请求指纹。
2. 对“本店/不限”的未观察业务含义存在猜测，真实门店扩展需另行权限隔离审查。
3. 必须共用同一 renderer bean，补齐页数一致性、同键重试和终态处理契约。
4. 错误码与异步解析失败语义必须沿用现有文件链。
5. Nginx 必须从完整 M5 运行配置增量生成，不得使用旧 M3 局部路由。

## 修订与增量复审

- 目录收窄为全公开、原创的新系统固定演示资源；不代表真实门店文库。
- 不再猜测“本店/不限”；该控件保持待只读观察和未完成状态。
- 信任输入将条目 ID 与内容版本纳入确定性 PDF 指纹，版本冻结；同键不同条目/版本返回冲突。
- 共用现有 singleton renderer、活动文件上限、解析、报价、订单、任务和回执链。
- 只有文件 `READY` 且解析页数等于固定预期页数才进入打印设置；`FAILED/DELETED`、超时或页数不符都阻断。
