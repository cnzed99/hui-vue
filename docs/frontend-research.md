# 云途智印 · 打印后台前端开发资料

检查日期：2026-10-22（Asia/Shanghai）。入口：https://youfan.iyint.com/depot/default.html 。当前账户菜单显示版本 V3.9.61698。

## 1. 范围与阅读方式

本资料用于重建商家打印后台前端的需求澄清、页面设计、组件拆分和前后端联调。依据为当前已登录账号的可见UI、字段、菜单链接、空白表单及仅查看的配置表单。未分析历史订单、会员或财务数据，实例值已从结构文本中省略。

覆盖6个业务区的52个侧栏入口，加工作台共53个入口；52个入口可读取页面，1个权限受限。此外补充23类二级表单模板，以及订单文件明细、文库购买记录2个附属只读页。入口数不等于独立页面模板数：多个订单与广告菜单共享模板、带不同参数。

只进行了导航、展开、分类选择、打开表单、读取与关闭；没有填写输入框、改变业务开关或勾选、保存、提交、删除、上下架、上传、执行打印、标记已打印、退款、提现、加款或更新数量。查看上传第二步时仅选择页面分类，未选择本地文件。未扫码绑定任何账户或设备。

“已观察”仅说明界面存在及字段可见；不代表写接口成功、操作链路可用、独立验收或实机通过。现网页面路由与参数仅是UI证据，不是已经取得的后端API。本文接口和组件内容均为开发建议。当前选择值不能当作系统默认值。

- 先看页面清单理解范围，再看二级表单与规则。
- `页面与表单清单.json`提供同源结构化清单、观察到的控件类型和DOM ID；DOM ID不能当API字段名。
- `中间文件/*.txt`为经实例值清理的结构摘录；`广告配置.png`为布局参考。
- 权限、关闭开关下的条件字段及未执行动作见待确认清单。

## 2. 页面框架与交互规范

已观察的桌面结构为蓝色顶部导航（工作台、门店、订单、财务、终端、会员、广告）、左侧深色分组菜单、右侧可关闭的多标签工作区与内容容器。账户下拉含版本与安全退出。子页面以嵌入页面形式显示，顶层URL常保持default.html；点击侧栏已打开的标签可能保留子页面内部导航状态。新实现应明确标签复用、返回列表及查询状态恢复规则。

建议组件：AppShell、PermissionGate、QueryBar、DateRange、PagedTable、StatusTabs、FormDialog、RegionCascade、DictionarySelect、SwitchField、UploadQueue、RichTextField、MetricCard、ChartPanel、AsyncActionStatus。组件名称为建议。

列表需处理加载中、查询无结果、无权限、读取失败和成功结果；分页总量是页面查询口径，不当数据库审计结果。通用列表多为10/20/40/100页容量；订单页另有200/500/1000/2000。大列数表格需要横向滚动、稳定行键及分页状态。开发时使用虚构数据。

表单应保留中文字段、单位、必填星号及提示，不仅复制输入框。金额建议统一以约定精度传输，时间范围约定时区与边界；实际舍入、最大范围、手机号格式等后端校验未获得，必须补齐。开关有“是否关闭”等反向文案，不能简单采用同一布尔映射。打开表单不等于提交；保存需有提交中、防重复、业务失败和字段错误反馈。密码只写/留空不改，禁止在新系统回显已有明文密码。

- `打印后台前端开发资料.md`：完整文字版，用于需求评审、拆任务和版本管理。
- `页面与表单清单.json`：页面、路由默认参数、字段、表格列、规则、表单模板、控件ID、接口能力需求和验收清单。
- `中间文件/导航清单.json`：52个侧栏入口；`*.txt`为结构观察摘录；`广告配置.png`为原界面布局参考；`build_reference.py`为生成脚本。

开发前先关闭G01–G03等阻断信息缺口，再确认接口契约。界面可以据此实现页面骨架与已知字段；不能将这份只读UI资料当作真实打印、支付结算和硬件协议的完整实现说明。
