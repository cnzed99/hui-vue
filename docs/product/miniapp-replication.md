# 云途智印小程序复刻记录

状态：持续补充

观察日期：2026-10-31

观察方式：Codex 在 Windows 微信小程序窗口中只读操作

约束：未上传、未搜索、未下单、未付款、未修改设置或资料；不记录用户完整标识。

## 全局框架

- 竖屏单列布局，暖橙色为品牌主色，内容区为浅灰背景、白色圆角卡片。
- 顶部为小程序自定义标题区；首页使用橙色渐变品牌头图，文库和“我的”使用橙色标题栏。
- 底部固定三项导航：`首页`、`文库`、`我的`。选中项使用橙色，未选中项为浅灰。
- 第一批实现以页面层级、信息密度、色彩、圆角、卡片和跳转关系为准；原站图片和真实账号数据不复制到新系统。

## 首页

### 已观察内容

- 品牌标题：云途智印。
- 店铺信息卡：门店名称、价目表入口、当前设备、校区/位置、通知文案。
- `常见打印` 为两列卡片：文档打印、图片打印、照片冲印、证件照、扫描复印、压缩包打印。
- `更多打印` 为图标入口：发票打印、文字速印、链接打印、试卷翻新；底部还有新手教程入口。
- 卡片具有彩色圆形图标、主标题和一行说明；首页滚动，底部导航固定。

### 第一批复刻差异

- 使用本地静态样例字段，不请求原系统接口，不复用原站联系方式或真实设备状态。
- 图标先用 CSS/字符图形近似，后续有合法品牌资产时再替换。
- 文档打印已进入新系统开发演示闭环；图片打印已进入目录与安全来源选择壳，照片、证件照、扫描复印、压缩包及其它“更多打印”入口仍显示预留提示。

## 文库

### 已观察内容

- 顶部标题：文库。
- 搜索栏占一行，提示文字为“输入文件名”，右侧为“搜索”按钮。
- 筛选栏四项：分类、本店、不限、排序，均带下拉指示。
- 文档列表为白色卡片：左侧预览缩略图，右侧依次显示标题、橙色分类/来源标签，以及浏览量、打印量、页数。
- 可见样例以英语四/六级真题为主，列表可纵向滚动。

### 第一批复刻差异

- 仅使用少量本地样例卡片；搜索只在本地筛选标题，筛选项暂显示占位提示。
- 不打开文档详情，不下载、打印或改变原文库计数。

## 文档打印（第二批）

### 已观察内容

- 首页点击“文档打印”进入同名页面，页面分为“常用打印”和“其它打印”。
- 常用入口为“微信聊天文档打印”，说明支持 Word、Excel、PDF、PPT。
- 其它入口包括：本地文档打印、压缩包打印、腾讯文档打印、金山文档打印、百度网盘文档打印、其它 APP 文档打印、A3 文档转 A4、PDF 解密打印、购买 A4 白纸。
- 本地文档入口进入“上传本地文件”页，页面提示支持 Word、PPT、PDF、Excel、图片，并提供橙色“选择本地文件打印”按钮。

### 第二批复刻差异与边界

- 新系统增加服务端只读目录接口；不可用时明确显示“本地目录 · 服务暂不可用”，不会伪装为已连接。
- H5/小程序页面可把 PDF 上传到新系统私有开发存储，由服务端真实解析页数和摘要；限制为 2MB、20页和暂存1小时。正式对象存储仍未接入。
- 固定演示文件入口仍保留并明确标识为演示结果；真实上传结果与固定 fixture 使用不同状态，不能互相冒充。
- 观察原小程序时未点击文件选择、未上传文件，且未记录原系统临时令牌或完整来源地址。

## 新系统文档打印闭环（第三、四批）

以下内容来自新系统开发验证，不是对原小程序进行写操作所得：

- 上传页建立独立演示会话，PDF 只进入新系统；服务端异步返回 READY/FAILED、页数和可解释失败原因。
- 打印设置页支持 A4、黑白、单双面和份数；彩色与其它规格继续明确为待确认，不在客户端生成最终金额。
- 确认订单页从服务端取得带版本报价；按“每个文件分别累计，份数计入该文件总张数”计价，阶梯命中后该文件全部纸张使用命中单价。
- 用户主动创建模拟订单和模拟支付；页面始终显示“不扣真实资金”，并可在重进页面后恢复订单和模拟收据。
- 配套后台订单详情可创建唯一模拟任务，按“领取→受理→开始执行→成功/失败/未知”推进；所有按钮均提示不会驱动真实打印机。
- 小程序轮询本人订单的打印任务；状态文案区分等待、领取、受理、执行、模拟成功、模拟失败和结果待人工核实。模拟成功回执明确“不代表真实出纸”。
- 2026-10-31 云端浏览器闭环已验证：后台 UI 实际写入模拟成功回执，小程序重新进入确认页后恢复同一订单、模拟支付和打印回执。微信开发者工具与真机仍为 `NOT_RUN`。

## 我的订单与订单详情（第五批）

### 原小程序已观察内容

- 从“我的”点击“我的订单”进入橙色标题栏页面，标题为“我的订单”，左侧为返回入口。
- 本次观察账号没有历史订单；空态为浅灰页面、中央空箱插画、“暂无订单哦~”和“已经没有更多信息了”。
- 因原账号无订单且原系统默认只读，本批未为观察而上传、下单或付款；原订单卡片、订单详情、筛选及售后按钮仍标记为未观察。

### 新系统实现与差异

- “我的订单”菜单已进入本人订单列表；服务端按 tenant、store、principal 三层作用域返回订单、总数和分页，跨主体详情与不存在详情保持相同 404。
- 空态复刻已观察的标题、空箱结构和两段文案；非空卡片根据新系统数据展示订单号、时间、页数、份数、单双面、纸张数、金额、模拟支付和模拟打印状态。
- 详情页重新向服务端读取，不信任列表缓存；订单、模拟支付收据和模拟打印结果分别查询，任一结果失败均显示“暂不可确认”，不会错误推断为未支付或未建任务。
- 页面隐藏时立即清除主体数据并使旧请求失效，重新显示时刷新；刷新、分页和会话变化均使用请求代次与 session/principal 上下文防止旧数据混入。
- 详情页只提供返回与刷新，不开放取消、退款、重打或真实支付；明确显示模拟支付不涉及真实资金、模拟回执不代表真实打印机出纸。
- 回环浏览器已验证个人页入口、非空列表、详情、刷新、返回和另一主体空态；微信开发者工具及真机仍为 `NOT_RUN`。

- 拍照、手机相册和微信图片按钮当前只显示“暂未接入，不会上传”，不调用系统相册或上传 API；AI高清、黑白、裁切、拼版参数、解析和计价仍为待观察/待设计，不能标记为完成。
