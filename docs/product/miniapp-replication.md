# 云途智印小程序复刻记录

状态：持续补充

观察日期：2026-10-31

观察方式：Codex 在 Windows 微信小程序窗口中只读操作

约束：未上传、未搜索、未下单、未付款、未修改设置或资料；不记录用户完整标识。

## 全局框架

- 竖屏单列布局，暖橙色为品牌主色，内容区为浅灰背景、白色圆角卡片。
- 顶部为小程序自定义标题区；首页使用橙色渐变品牌头图，文库和“我的”使用橙色标题栏。
- 底部固定三项导航：`首页`、`文库`、`我的`。选中项使用橙色，未选中项为浅灰。
- 第一批实现以页面层级、信息密度、色彩、圆角、卡片和跳转关系为准；原站图片和真实账号数据不复制到新系统。

## 首页

### 已观察内容

- 品牌标题：云途智印。
- 店铺信息卡：门店名称、价目表入口、当前设备、校区/位置、通知文案。
- `常见打印` 为两列卡片：文档打印、图片打印、照片冲印、证件照、扫描复印、压缩包打印。
- `更多打印` 为图标入口：发票打印、文字速印、链接打印、试卷翻新；底部还有新手教程入口。
- 卡片具有彩色圆形图标、主标题和一行说明；首页滚动，底部导航固定。

### 第一批复刻差异

- 使用本地静态样例字段，不请求原系统接口，不复用原站联系方式或真实设备状态。
- 图标先用 CSS/字符图形近似，后续有合法品牌资产时再替换。
- 所有打印入口目前只显示“接口待接入”提示，不上传文件或创建订单。

## 文库

### 已观察内容

- 顶部标题：文库。
- 搜索栏占一行，提示文字为“输入文件名”，右侧为“搜索”按钮。
- 筛选栏四项：分类、本店、不限、排序，均带下拉指示。
- 文档列表为白色卡片：左侧预览缩略图，右侧依次显示标题、橙色分类/来源标签，以及浏览量、打印量、页数。
- 可见样例以英语四/六级真题为主，列表可纵向滚动。

### 第一批复刻差异

- 仅使用少量本地样例卡片；搜索只在本地筛选标题，筛选项暂显示占位提示。
- 不打开文档详情，不下载、打印或改变原文库计数。

## 我的

### 已观察内容

- 顶部标题：我的；橙色用户区域包含头像、昵称、用户标识与设置入口。
- 下方为会员横幅，展示会员类型、绑定门店和“查看详情”。
- 功能列表：我的订单、会员卡、代金红包、我的文库、服务中心、我要加盟、隐私协议。
- `我的订单` 右侧有“售后服务与支持”提示，其余项目使用右箭头。

### 第一批复刻差异

- 使用“微信用户”和掩码标识，不保存或展示观察账号的完整用户标识。
- 功能项只保留布局和本地提示；微信登录、订单、会员、红包和售后接口尚未接入。

## 已验证跳转

- 首页 → 文库 → 我的三项底部导航可正常切换。
- 页面切换没有触发上传、下单、付款或资料修改。
