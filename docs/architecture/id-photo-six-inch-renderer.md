# 六寸证件照离线排版候选

纯 renderer 接收已解码且校正方向的无透明 RGB 图片。输出一页 152×102 mm 的横向 PDF，Rotate=0。位置使用 72/25.4 pt/mm 换算，每份图片在所属 cell 等比居中。二寸以 PDF 图像矩阵顺时针转 90°，页面不旋转。共享裁切线绘制一次，并限制在整版矩形内。

| 规格 | 证件照尺寸 (mm) | cell (mm) | 列×行 | 左右／上下边距 (mm) |
|---|---:|---:|---:|---:|
| 一寸 | 25×35 | 25×35 | 5×2 | 13.5／16 |
| 二寸 | 35×49 | 49×35 | 2×2 | 27／16 |
| 三寸 | 55×84 | 55×84 | 2×1 | 21／9 |

离线检查仅用合成图片。真实照片、真实打印机及纸张偏差均未验证。此候选未接入 API、数据库、订单或计价，不改变现有 A4 图像解码/渲染。

输入宽度最多 2400 px、高度最多 3394 px，总像素最多 8,145,600。非正尺寸和超限尺寸在取像素与编码前拒绝。二寸使用放置矩阵旋转，输入上限不交换。

嵌入图按各规格的原始物理照片尺寸计算 300 DPI 像素上限。超出包络的输入使用双三次插值等比缩小，较小的源图保持像素尺寸；原输入比例决定 PDF 放置矩阵。每页只嵌入一份 JPEG，再重复绘制。固定质量顺序为 0.92、0.88、0.84。PDF 字节输出上限 2 MiB，所有档次都超限时以固定异常拒绝。稳定文档 ID 包含渲染版本、规格、原图尺寸、实际嵌入像素尺寸、所用质量和嵌入像素摘要。

在独立 192 MiB JVM 中，用最大尺寸高熵合成图验证三档，均使用 0.92，PDF 分别为 112,237／217,849／540,371 B，有效分辨率分别为 300.45／300.13／300.18 DPI。同一输入重复编码字节一致。输出大小和分辨率仅为离线合成样件结果，不能视为真实打印验收。
