# 六寸证件照离线排版候选

纯 renderer 接收已解码且校正方向的无透明 RGB 图片。输出一页 152×102 mm 的横向 PDF，Rotate=0。位置使用 72/25.4 pt/mm 换算，每份图片在所属 cell 等比居中。二寸以 PDF 图像矩阵顺时针转 90°，页面不旋转。共享裁切线绘制一次，并限制在整版矩形内。

| 规格 | 证件照尺寸 (mm) | cell (mm) | 列×行 | 左右／上下边距 (mm) |
|---|---:|---:|---:|---:|
| 一寸 | 25×35 | 25×35 | 5×2 | 13.5／16 |
| 二寸 | 35×49 | 49×35 | 2×2 | 27／16 |
| 三寸 | 55×84 | 55×84 | 2×1 | 21／9 |

离线检查仅用合成图片。真实照片、真实打印机及纸张偏差均未验证。此候选未接入 API、数据库、订单或计价，不改变现有 A4 图像解码/渲染。
